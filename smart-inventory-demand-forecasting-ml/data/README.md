# Dataset setup

Download the **Retail Store Inventory Forecasting Dataset** from Kaggle:

https://www.kaggle.com/datasets/anirudhchauhan/retail-store-inventory-forecasting-dataset

Place the downloaded CSV in this folder using either filename:

- `retail_store_inventory-2.csv`
- `retail_store_inventory.csv`

The notebook checks both names. Do not commit the raw dataset unless you have checked the dataset page's current license/terms and decided redistribution is appropriate. The `.gitignore` excludes CSV files in this directory by default.
